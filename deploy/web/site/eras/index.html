Community servers run Asheron's Call from three points in its history: the end of retail (the game as Turbine left it in 2017), the classic Dark Majesty era before Throne of Destiny, and AC1999, the original launch. webAC plays all three in the browser and loads each era's own game data, so you never install a second client.

What each era is like

End of retail (2017)

The game as Turbine left it when the servers closed: every expansion, the final interface and all 13 heritages. Most servers run this era, many with their own additions.

Dark Majesty (classic)

The world before Throne of Destiny, with the classic skills and loot. Seedsow, Snowreap, Dekarutide and Unfamiliar Shores run it. In webAC these worlds use the end-of-retail interface over their own world data. With the original client they need that server's own classic game files.

AC1999

The game as it shipped on 2 November 1999, on its own server software. webAC shows the 1999 world and rules with its end-of-retail interface. Expect 1999 rules: no purple bubbles when you log out (those came in a later patch), and you need a wand or other caster in hand to cast spells.

Questions

Can I play Asheron's Call from before Throne of Destiny?

Yes. Classic servers such as Seedsow, Snowreap and Dekarutide run the Dark Majesty era, and webAC plays them in the browser. GDLE, classic and 1999 worlds are in beta.

Can I play Asheron's Call as it was in 1999?

Yes. The AC1999 server runs the game as it launched, and webAC plays it in the browser, in beta.

Do I need classic game files or an old client?

Not with webAC: it loads each era's data for you. With the original client, classic worlds need that server's classic files (some also a patched client), and AC1999 needs the original 1999 client.
