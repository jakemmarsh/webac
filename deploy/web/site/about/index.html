What is webAC?

webAC is a free, open-source game client for Asheron's Call, Turbine's 1999 MMORPG, that runs entirely in your web browser. It connects to the community's emulator servers, the same worlds you would reach with the original client and ThwargLauncher, and it uses your existing account on those servers.

It was written from scratch in TypeScript and WebGL. The interface, fonts, art, models and sounds all come from the original game data, and the goal is to look and behave exactly like the retail client, quirks included.

Questions

Can I play Asheron's Call in a web browser?

Yes. Open playwebac.com in Chrome, Firefox or Safari, pick a world from the public server list, log in with your account on that server, and play. There is no client, launcher or game-file download.

Can I play Asheron's Call on a Mac?

Yes. Because webAC runs in the browser, it works on a Mac, on Linux and on Windows, without Wine, a virtual machine or the original client. You need a desktop or laptop with a mouse and a browser with WebGL 2. Phones and tablets aren't supported.

Which servers does webAC work with?

  • ACE (ACEmulator) servers running the end-of-retail game, as of the January 2017 shutdown.
  • Classic servers set in the Dark Majesty era.
  • AC1999, the game as it was at its 1999 launch.
  • GDLE servers. Login, character creation, NPCs, vendors and chat work; combat, magic and trading are still being tested.

The world list is the community server list that ThwargLauncher also uses.

Do I need to install anything or download the DAT files?

No. webAC streams only the game data it needs as you play, so you are usually in the world in under a minute.

Do I need a new account?

No. Use the account you already have on the server you play on. Most ACE worlds create your account the first time you log in; some ask you to register on their website first, and the launcher says which.

What happens to my login and data?

  • Your login travels from your browser to webAC's relay over an encrypted connection, and the relay passes it to the world's server using AC's own protocol. It is never logged or stored.
  • webAC has no accounts database. Your characters live on the server you play on.
  • Basic connection logs (IP address, world, session length) and anonymous crash reports are kept. No analytics, no cookies, no trackers.
  • Your settings, keybinds and window layout are saved in your own browser.

Is webAC free?

Yes. webAC is free and open source under the AGPL-3.0 license. The source code is on GitHub.

Is it finished?

It's in public beta. Expect bugs, especially on less common servers, and please report them on GitHub.

Credits

webAC stands on years of community work: the ACE server project, whose source is the reference for the protocol and game rules; GDLE; ACViewer, for the DAT formats; the AC1999 project; and ThwargLauncher's server list. webAC was built with heavy use of an AI coding assistant (Claude); everything you see and hear in the game comes from the original game files.
